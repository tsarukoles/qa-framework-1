# Vault map

The vault is the folder of project notes kept beside the code. Start here.

| Folder | What it holds |
|---|---|
| `_raw/` | Rough notes that are not yet sorted. Empty for now; `.gitkeep` keeps the folder in Git. |
| `_changelog/` | Automatic records. `YYYY-MM-DD.md` lists every file Claude changed that day (tracked). `sessions.log` lists session starts (ignored by Git). |
| `03-framework/` | Explanations of the framework. `hook-lifecycle-map.md` shows which Claude Code hooks are connected, when they run and what has been verified. |

Nothing in this folder is edited by the recorder except `_changelog/`. The recorder never records changes to the vault itself.
